# Story 2.2: Adicionar Testes E2E de Navegador (Boot PWA, Autenticação, Navegação e CRUD)

## Status

Done

## Story

**As a** desenvolvedor e maintainer do PainelAtende,
**I want** uma suíte de testes E2E automatizada simulando o navegador,
**so that** possamos validar o fluxo completo da aplicação (boot do PWA, erros de autenticação, navegação entre abas e CRUD de mensagens/links/problemas) e evitar regressões de integração.

## Acceptance Criteria

1. O script `"test:e2e"` é adicionado ao `package.json`.
2. O arquivo `tests/e2e-browser.test.js` é criado cobrindo:
   - Boot do PWA (estrutura HTML5, container `<main id="app">`, temas e SW).
   - Fluxo de erro de autenticação e feedback visual ao usuário.
   - Navegação entre as abas (`tabMessages`, `tabProblems`, `tabLinks`, `tabSistemas`).
   - CRUD de Mensagens (Criação, Leitura, Edição, Duplicação e Exclusão).
   - CRUD de Links Úteis (Criação, Busca e Exclusão).
   - CRUD de Problemas e Soluções (Criação com tags, status e duplicação).
3. O novo arquivo `tests/e2e-browser.test.js` é registrado em `tests/run-all.js`.
4. Todos os quality gates (`npm run lint`, `npm run typecheck`, `npm run build`, `npm test`) passam sem erros.
