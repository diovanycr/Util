# Story 2.8: Lazy-loading das Ferramentas no Port Opener

## Status

Done

## Story

**As a** desenvolvedor e usuário do PainelAtende,
**I want** carregamento sob demanda (lazy-loading) dos submódulos de ferramentas no Port Opener,
**so that** o consumo inicial de memória e o tempo de renderização da aba "Sistemas & Ferramentas" sejam reduzidos ao mínimo, carregando scripts como `decisionTree.js` (~30 KB) e validadores apenas quando o usuário acioná-los.

## Acceptance Criteria

1. **Desacoplamento e Importação Dinâmica (`js/tools/portOpener.js`)**:
   - Removidos imports estáticos de topo de nível dos submódulos de ferramentas secundárias (`escPos.js`, `docValidatorUI.js`, `statusChecker.js`, `apiTester.js`, `fileValidator.js`, `ticketSummary.js`, `decisionTree.js`, `networkDiag.js`, `scriptGen.js`, `futura-widget.js`).
   - Implementado mapa de carregamento dinâmico `TOOL_LOADERS` utilizando `import()` dinâmico do ESM.
   - Atualizado `renderSistemasTab(container)` para construir apenas o painel base do Port Opener no boot.

2. **Feedback Visual e Modal de Abertura (`js/tools/portOpener.js`)**:
   - `_openToolModal(tool, btnEl, container)` adaptado para exibir mensagem e spinner de carregamento ("Carregando ferramenta...") caso o módulo ainda não tenha sido importado.
   - Tratamento de exceção amigável caso haja falha de carregamento de rede.

3. **Suíte de Testes Unitários (`tests/lazy-tools.test.js`)**:
   - Criados testes unitários estáticos validando a ausência de imports estáticos no topo, a presença da tabela `TOOL_LOADERS` e a manutenção das exportações públicas `renderSistemasTab` e `cleanupPortOpener`.

4. **Quality Gates**:
   - Todos os quality gates (`npm run lint`, `npm run typecheck`, `npm run build`, `npm test`) passando com 100% de sucesso.
