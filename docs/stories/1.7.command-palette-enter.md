# Story 1.7: Corrigir Enter na Command Palette

## Status

Ready for Review

## Story

**As an** usuário da Command Palette (`Ctrl+K`),
**I want** que a tecla `Enter` no resultado selecionado abra/navegue para o item (mensagem, problema, link ou comando),
**so that** eu possa ir até o conteúdo escolhido de forma rápida e intuitiva, mantendo a cópia direta como ação secundária.

## Acceptance Criteria

1. Pressionar `Enter` na Command Palette aciona a ação primária (`selected.click()`) do resultado selecionado.
2. Resultados do tipo Mensagem navegam para a aba `tabMessages`, aplicam o filtro de busca e fecham a busca.
3. Botão secundário de cópia (`.search-copy-btn`) mantém a funcionalidade de cópia rápida para a área de transferência.
4. Resultados do tipo Comandos, Ferramentas, Problemas e Links continuam funcionando corretamente.
5. Testes unitários validam o acionamento via `Enter` e a navegação da mensagem.
6. Todos os quality gates e a suíte de testes passam localmente.
