# Story 1.6: Landmarks Semânticos e Navegação por Skip-Link

## Status

Ready for Review

## Story

**As an** usuário de tecnologia assistiva ou teclado,
**I want** que a aplicação possua landmarks semânticos HTML5 (`<header>`, `<main>`, `<nav>`) e um skip-link com foco funcional,
**so that** eu possa navegar rapidamente entre as seções principais da página usando leitores de tela ou atalhos de teclado.

## Acceptance Criteria

1. O container principal do aplicativo utiliza a tag `<main id="app" class="container hidden" tabindex="-1">`.
2. O cabeçalho principal utiliza a tag `<header class="header">`.
3. As abas de navegação principais do painel são envoltas por uma tag `<nav aria-label="Navegação do painel">`.
4. O link de acessibilidade `.skip-link` aponta para `#app`, que possui `tabindex="-1"` e pode receber foco.
5. As caixas de busca de página utilizam `role="search"`.
6. Testes automatizados verificam a presença dos landmarks HTML5 e atalhos de acessibilidade.
7. Todos os quality gates e a suíte de testes passam sem erros.

## Dev Notes

- O atributo `tabindex="-1"` no `<main>` é fundamental para permitir que o navegador posicione o foco de teclado no elemento quando o usuário clica em "Ir para o conteúdo principal" (`.skip-link`).
- Mantém os IDs e classes CSS (`id="app"`, `.header`, `.tabs`) para evitar quebras em seletores de JS ou CSS.
