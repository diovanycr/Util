# Story 2.9 — Cloud Function `adminDeleteUser`

## Objetivo
Permitir que administradores excluam usuários completos do Firebase (Auth + Firestore), de forma segura e auditável, sem depender de remoção direta no cliente.

## Problema
A exclusão anterior removia apenas documentos do Firestore. O registro no Firebase Auth permanecia, permitindo que o usuário continuasse se autenticando e recriando dados.

## Solução implementada

### `functions/index.js`
Adicionada Cloud Function `adminDeleteUser` (callable, v2):
- Verifica autenticação do chamador
- Verifica `role === "admin"` no Firestore (autorização server-side)
- Apaga todas as subcoleções do usuário alvo: `messages`, `problems`, `links`, `history`, `auditReset`, `preferences`
- Remove o documento root do usuário
- Chama `admin.auth().deleteUser(targetUid)` com tratamento de erro (log + continuação)

### `js/modules/admin.js`
- Chama `adminDeleteUser` via `httpsCallable` com `{ targetUid }`
- Fallback local para remover documentos Firestore caso a função não esteja disponível

### `tests/cloud-functions.test.js`
- Asserta existência de `adminDeleteUser` no código-fonte da função
- Valida verificação de papel `admin` e uso de `deleteUser`
