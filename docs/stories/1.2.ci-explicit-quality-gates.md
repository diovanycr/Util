# Story 1.2: Explicit Quality Gates in GitHub Actions CI

## Status

Ready for Review

## Story

**As a** maintainer,
**I want** dedicated CI steps for `validate:port-denylist`, `typecheck`, and `build` in `.github/workflows/ci.yml`,
**so that** each quality gate reports its status independently in pull requests and CI logs.

## Acceptance Criteria

1. `.github/workflows/ci.yml` includes individual steps for `validate:port-denylist`, `typecheck`, and `build`.
2. The steps execute prior to `npm run lint` and `npm test`.
3. Automated test suite verifies that all quality gate scripts remain configured in the CI workflow.
4. All quality gates and test suites pass locally.
