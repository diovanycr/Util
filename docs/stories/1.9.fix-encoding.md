## Dev Notes

- Mojibake ocorre quando arquivo ISO-8859-1 é lido como UTF-8. Os bytes `0xC3 0xA3` = `ã`, `0xC3 0xA7` = `ç`, etc.
- Apenas `js/modules/links.js` apresenta linhas afetadas (9 linhas com Mojibake nos comentários e strings de modal).
- Os outros arquivos (`auth.js`, `loader.js`, `fileValidator.js`) têm caracteres Unicode normais — apenas caracteres compostos legítimos, não Mojibake.
