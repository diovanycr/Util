# Story 1.1: Quality Gates for Local Delivery

## Status

Ready for Review

## Story

**As a** maintainer,
**I want** executable quality-gate commands for type checking, static build verification, and local endpoint validation,
**so that** the repository can validate changes before a pull request is opened.

## Acceptance Criteria

1. `npm run typecheck` validates the syntax of application, script, and test JavaScript files.
2. `npm run build` performs a static build verification and validates the service-worker pre-cache.
3. `npm run validate:port-denylist` rejects local development HTTP endpoints in shipped application files.
4. The commands are covered by the automated test suite and all existing tests remain green.
5. The GitHub Actions Node matrix supports the runtime requirements of the locked test dependencies.
