# Story 1.3: Centralized Modal Accessibility

## Status

Ready for Review

## Story

**As an** accessibility user,
**I want** all modal dialogs to manage initial focus, focus trap, escape key closing, focus restoration, and ARIA attributes centrally,
**so that** navigating dialogs with keyboard or screen readers is safe, predictable, and fully accessible across the application.

## Acceptance Criteria

1. Opening any modal dialog focuses a defined target element or the first focusable element inside the modal.
2. Tab and Shift+Tab wrap focus strictly inside the open modal dialog (Focus Trap).
3. Pressing the `Escape` key closes the topmost open modal and cancels confirm modals gracefully.
4. Closing any modal restores focus to the element that triggered it.
5. All modal HTML containers define `role="dialog"` or `role="alertdialog"`, `aria-modal="true"`, and appropriate `aria-labelledby`/`aria-label`.
6. Unit tests verify focus trapping, Escape key closing, focus restoration, and ARIA attributes.
7. All quality gates and test suites pass locally.
