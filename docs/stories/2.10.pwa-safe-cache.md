# Story 2.10 — Atualizar o cache do PWA com segurança

## Objetivo
Eliminar a lista de assets hardcoded no Service Worker, versionar o pre-cache por hash de conteúdo e implementar um fluxo de atualização controlado pelo usuário com toast de notificação.

## Problema
| Ponto de dor | Impacto |
|---|---|
| `CACHE_NAME = 'painelatende-v111'` manual | Esquecimento → usuário usa versão velha sem saber |
| Lista de ~100 arquivos hardcoded em `sw.js` | Arquivo novo = não cacheado; arquivo removido = 404 no install |
| `self.skipWaiting()` automático no `install` | Nova versão ativa imediatamente, quebrando abas abertas |
| Nenhum aviso ao usuário | Atualizações silenciosas e invisíveis |

## Solução implementada

### `scripts/generate-sw-manifest.js` (novo)
- Varre `css/` e `js/` recursivamente + arquivos raiz
- Filtra por extensão cacheável (`.css`, `.js`, `.html`, `.json`, etc.)
- Exclui `node_modules`, `sw.js`, `sw-manifest.json`
- Computa SHA-256 parcial (8 KB) de cada arquivo
- Gera `version` como hash global (SHA-256 de todos os hashes individuais, 12 chars)
- Escreve `sw-manifest.json` com `{ version, generatedAt, files }`

### `scripts/build-check.js`
- Geração do manifesto adicionada como **primeiro step** do build

### `package.json`
- Novo script `"generate:sw": "node scripts/generate-sw-manifest.js"`

### `sw.js`
- Remove lista hardcoded (era ~100 linhas)
- No `install`: lê `sw-manifest.json` via `fetch` e passa para `cache.addAll()`
- `CACHE_NAME` = `painelatende-<version-do-manifesto>` → automático por conteúdo
- Remove `self.skipWaiting()` do install
- Handler de mensagem `{ type: 'SKIP_WAITING' }` → chama `skipWaiting()` sob demanda
- `activate` limpa caches antigos por prefixo

### `js/boot/sw-register.js`
- Detecta `registration.waiting` na carga e `updatefound` → `installed` durante a sessão
- Toast acessível (`role="status"` + `aria-live="polite"`) com botão "Atualizar agora"
- Ao clicar: `worker.postMessage({ type: 'SKIP_WAITING' })` → `controllerchange` → reload
- Evita múltiplos toasts simultâneos

### `tests/sw.test.js`
Substituição dos asserts antigos (lista hardcoded) por:
- `CACHE_PREFIX` definido
- `skipWaiting` **não** está dentro do handler `install`
- Mensagem `SKIP_WAITING` é tratada
- `sw-manifest.json` é referenciado (sem paths hardcoded)
- `activate` deleta caches antigos
- Todos os arquivos do manifesto existem em disco

### `tests/sw-manifest.test.js` (novo)
- Manifesto existe em disco
- JSON válido com `version`, `files` e `generatedAt`
- Todos os arquivos listados existem
- Cobre CSS e JS
- `sw.js` não está listado (evita referência circular)
