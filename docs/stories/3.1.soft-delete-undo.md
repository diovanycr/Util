# Story 3.1: Padronizar exclusão recuperável (soft-delete + toast "Desfazer")

## Status

Done

## Story

**As an** usuário do PainelAtende,
**I want** que a exclusão de mensagens, problemas e links seja feita via exclusão recuperável (*soft-delete*) com um toast interativo contendo a opção "Desfazer",
**so that** eu possa recuperar itens excluídos acidentalmente antes da exclusão definitiva no Firestore.

## Acceptance Criteria

1. **Serviço Centralizado de Undo (`js/core/undoService.js`)**:
   - Criação de um utilitário reutilizável que gerencia a janela de desfazer (ex: 8 segundos).
   - Suporta agendamento da deleção real no Firestore ao expirar o tempo sem ação do usuário.
   - Oferece suporte ao cancelamento e restauração do estado visual caso o usuário clique em "Desfazer".

2. **Integração nas Mensagens (`js/modules/messages.js` / `trash.js`)**:
   - Ao remover uma mensagem, oculta visualmente a mensagem de imediato e exibe um toast: *"Mensagem movida para a lixeira. [Desfazer]"*.
   - Se "Desfazer" for acionado, a mensagem é restaurada no DOM sem efetuar a chamada de exclusão no Firestore/Trash.

3. **Integração nos Problemas (`js/modules/problems.js`)**:
   - Ao excluir um problema, aplica exclusão temporária local e exibe o toast com "Desfazer".
   - Se o tempo expirar sem clique, a deleção no Firestore é confirmada.

4. **Integração nos Links (`js/modules/links.js`)**:
   - Aplica a mesma mecânica de exclusão recuperável com toast para os links úteis.

5. **Testes Automatizados (`tests/undo-delete.test.js`)**:
   - Valida o comportamento do `undoService` (timers, cancelamento, callbacks de deleção final e restore).
   - Valida que as funções de exclusão nos módulos acionam o serviço de desfazer.

6. **Quality Gates**:
   - Todos os quality gates (`npm run validate:port-denylist`, `npm run typecheck`, `npm run build`, `npm run lint`, `npm test`) devem passar sem erros.
