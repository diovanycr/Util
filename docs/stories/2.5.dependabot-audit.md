# Story 2.5: Automação de Atualização e Auditoria de Dependências (Dependabot & Scheduled Audit)

## Status

Done

## Story

**As a** desenvolvedor e responsável por DevOps/Segurança do PainelAtende,
**I want** atualizações automáticas de dependências via Dependabot e auditoria de vulnerabilidades de segurança agendada no CI,
**so that** o projeto mantenha bibliotecas e GitHub Actions atualizados sem vulnerabilidades conhecidas.

## Acceptance Criteria

1. **Configuração do Dependabot (`.github/dependabot.yml`)**:
   - Criado `.github/dependabot.yml` configurado para monitorar ecossistemas `npm` e `github-actions` semanalmente.
   - Definidos agrupamentos inteligentes de atualizações e limites de PRs abertos.

2. **Workflow Agendado de Auditoria (`.github/workflows/audit.yml`)**:
   - Criado workflow `.github/workflows/audit.yml` com trigger cron agendado (toda segunda-feira às 06:00 UTC) e `workflow_dispatch` manual.
   - Execução de `npm audit --audit-level=high` garantindo que nenhuma vulnerabilidade grave ou crítica passe despercebida.

3. **Verificação de Quality Gates (`tests/quality-gates.test.js`)**:
   - Adicionadas asserções em `tests/quality-gates.test.js` garantindo a existência e validação sintática do `.github/dependabot.yml` e do workflow `.github/workflows/audit.yml`.

4. **Gates de Qualidade**:
   - Todos os quality gates (`npm run lint`, `npm run typecheck`, `npm run build`, `npm test`, `npm audit --audit-level=high`) passam sem erros.
